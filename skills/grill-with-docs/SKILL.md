Read [grilling](../grilling/SKILL.md) and [domain-modeling](../domain-modeling/SKILL.md). Use the interview's dependency-ordered rounds; as answers resolve terminology or consequential choices, apply the domain-modeling workflow to the existing glossary and decision layout.

Keep unresolved choices proposed and link accepted decisions to their rationale. Return the settled design, changed document paths, and questions still blocking the next step. This combines the two workflows in the current session; it does not require a host-specific Skill tool.
