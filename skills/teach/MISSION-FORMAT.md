# Learning mission

Store this within the agreed learning workspace as `MISSION.md`:

```md
# Mission: Topic

Goal: The practical capability this learning should produce.
Success: A task the learner will complete or explain independently.
Constraints: Time, budget, prior knowledge, and learning preferences.
Out of scope: Adjacent topics that can wait.
```

Use one coherent goal per mission. Separate unrelated tracks when their records would otherwise confuse the next lesson. Revise the mission when the user's goal changes, preserving the reason in a learning record.
