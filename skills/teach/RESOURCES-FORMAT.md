# Learning resources

Store a short annotated list as `RESOURCES.md` in the learning workspace:

```md
# Topic resources

- [Source title](https://example.com): What it covers and when to use it.
```

Replace the illustrative URL with a checked source when creating a real list. Prefer original papers, official documentation, and appropriate books. Identify edition/version when it affects a claim. Mark disagreements and gaps rather than filling them with unsupported explanations.

Include a practitioner community only when outside feedback serves the learning goal and suits the user's preferences. Remove sources shown to be unreliable or irrelevant; a long unannotated reading list does not establish progress.
