# Prepare and verify a release

Identify the artifact/version, environment, owner, user impact, and release authority. Assemble the project's required build/test/security/eval evidence; distinguish failed, blocked, and unrun gates.

Produce a release plan with compatibility, migrations/backfills, smoke checks, abort criteria, rollback limitations, forward recovery, and backup/restore evidence. Include alert owner, cost/quotas, provider fallback, and incident path for operated systems.

Promote the tested artifact where practical. If authority is missing, finish safe preparation and present the exact destination, effects, evidence, and remaining boundary. If authority exists, execute and verify within it.

Return artifact/source/environment identifiers, performed effects, post-release evidence, recovery pointers, and residual limits. A research release can be a permitted reproducibility bundle rather than a hosted service.
