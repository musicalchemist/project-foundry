# Plan around unresolved risk

Test feasibility across value, technical capability, data rights/quality, capacity, and operating cost. Classify the decision: proceed, spike first, narrow, blocked on a named prerequisite, or park. Attach evidence, confidence, and unresolved assumptions.

Scope the smallest useful result and exclusions. For refactors, name preserved contracts/callers and characterization checks. For research, separate execution milestones from evidence needed to support a claim.

Order milestones by dependencies and risk. Detail only the near-term tasks; each needs an outcome, prerequisite, relevant interface/path, acceptance check, and stop condition. Estimate ranges with assumptions, then revise after the first slice.

Return the feasibility decision, milestone table, current/next/blocked work, deferred scope, and the first task contract. A spike needs a cap, pass/fail criteria, and the decision it unlocks.
