# Save the next session's starting state

Record objective/mode, acceptance criteria, repo/worktree/branch, active instructions, changed files, user work to preserve, decisions/evidence, assumptions, and authorization already given.

Include commands/results, failure evidence, artifact/data versions and permitted locations, remaining budget if known, unresolved blockers, and the next exact task with prerequisites and stop conditions. Exclude secrets and restricted raw data.

Keep recoverable detail as file/artifact pointers. Preserve decision rationale and unresolved uncertainty in the summary; do not replace them with a generic “continue building.”

On resume, compare the handoff with current files/status before acting. Checkpoint at decisions or milestones, not every edit. Bound repeated searches/attempts; record why another attempt could change the outcome.
